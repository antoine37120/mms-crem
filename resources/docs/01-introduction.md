# Introduction au MMS (Système de Management de Médias)

Bienvenue dans la documentation utilisateur du MMS. Cette application a pour but de gérer les archives multimédias du CREM.

## Objectifs

L'objectif principal est de permettre le classement, la description et la conservation de fichiers audio, vidéo et documents associés (livrets, traductions, etc.) au sein d'une structure hiérarchique claire.

## Structure des données

Le système repose sur une hiérarchie à plusieurs niveaux :

1.  **Fonds** : Le niveau le plus élevé (ex : `CNRSMH_Arnaud`). Il regroupe un ensemble cohérent d'archives.
2.  **Corpus** : Subdivision thématique ou chronologique d'un fonds (ex : `CNRSMH_Arnaud_001`).
3.  **Collections** : Groupes d'enregistrements au sein d'un corpus (ex : `CNRSMH_I_2011_001`).
4.  **Items** : Les fichiers eux-mêmes. Il peut s'agir d'enregistrements principaux (sons, vidéos) ou de fichiers secondaires (documents texte, images).

## Navigation dans la documentation

Utilisez le menu pour naviguer entre les différentes sections de cette documentation :

*   **Gestion des Archives** : Pour comprendre comment créer et modifier les fonds, corpus et collections.
*   **Médias & Items** : Pour tout savoir sur l'upload de fichiers et la gestion des items.
*   **Outils d'Exploration** : Pour découvrir comment naviguer efficacement dans vos données via la vue hiérarchique.
*   **Administration** : Pour la gestion des utilisateurs et des accès.
